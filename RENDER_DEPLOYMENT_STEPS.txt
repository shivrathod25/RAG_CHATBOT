1. PREREQUISITES
================================================================================
1. A Render account (Sign up for free at: https://render.com)
2. Your GitHub repository connected to Render (https://github.com/shivrathod25/RAG_Chatbot)
3. A Google Gemini API Key from Google AI Studio: https://aistudio.google.com

================================================================================
2. OPTION A: 1-CLICK BLUEPRINT DEPLOYMENT (FASTEST & EASIEST)
================================================================================
The project includes a `render.yaml` configuration that sets everything up automatically.

1. Go to your Render Dashboard: https://dashboard.render.com
2. Click the "New +" button in the top navigation bar.
3. Select "Blueprint".
4. Connect and select your GitHub repository: "shivrathod25/RAG_Chatbot".
5. Render will read `render.yaml` and configure the build and start commands automatically.
6. Under the "Environment Variables" prompt:
   - Enter your `GOOGLE_API_KEY` (e.g., AIzaSy...).
7. Click "Apply".
8. Render will build and deploy your application. In ~2-3 minutes, your live URL will be ready!

================================================================================
3. OPTION B: MANUAL WEB SERVICE DEPLOYMENT
================================================================================
If you prefer configuring the Web Service manually:

1. Go to https://dashboard.render.com and click "New +" -> "Web Service".
2. Select "Build and deploy from a Git repository".
3. Choose the repository: "shivrathod25/RAG_Chatbot".
4. Fill in the following settings:
   -----------------------------------------------------------------------
   Setting             | Value
   -----------------------------------------------------------------------
   Name                | rag-chatbot-app  (or any name you prefer)
   Region              | Singapore or Oregon (any preferred region)
   Branch              | main
   Root Directory      | (Leave empty)
   Runtime             | Python 3
   Build Command       | pip install -r requirements.txt
   Start Command       | uvicorn backend.app:app --host 0.0.0.0 --port $PORT
   Instance Type       | Free
   -----------------------------------------------------------------------

5. Scroll down to "Environment Variables" and add:
   -----------------------------------------------------------------------
   Key                 | Value
   -----------------------------------------------------------------------
   GOOGLE_API_KEY      | Your Google Gemini API Key from AI Studio
   PYTHON_VERSION      | 3.11.9
   -----------------------------------------------------------------------

6. Click "Create Web Service".

================================================================================
4. HOW TO ADD OR UPDATE CREDENTIALS LATER
================================================================================
If you deploy first and need to add or update your credentials later:

1. In Render Dashboard, click on your deployed Web Service (`rag-chatbot-app`).
2. In the left-hand navigation menu, click "Environment".
3. Click "Add Environment Variable".
4. Set:
   - Key: `GOOGLE_API_KEY`
   - Value: `your_actual_gemini_api_key_here`
5. Click "Save Changes".
6. Render will automatically perform a zero-downtime redeploy with the updated credentials!

================================================================================
5. LIVE VERIFICATION & TESTING
================================================================================
Once deployed, open your live Render URL (e.g. `https://rag-chatbot-app.onrender.com`):

1. The interactive web chat interface will open directly at the root URL.
2. The status indicator in the top navbar should show "FastAPI Live Backend" (Green).
3. Try asking sample queries:
   - Greeting: "Hi, what topics can you assist me with?"
   - Machine Learning: "What is Unsupervised Learning?"
   - HR Policy: "What is the annual leave entitlement?"
   - IT Security: "What are the password requirements?"
4. You can also view Swagger API Documentation at `https://<your-service>.onrender.com/docs`.

================================================================================
6. FREE TIER NOTES
================================================================================
- Render Free Tier instances spin down after 15 minutes of inactivity.
- When you first visit the URL after inactivity, it may take 30-45 seconds to wake up.
- All PDF documents (HR_Policy.pdf, IT_Security_Policy.pdf, ML.pdf) are automatically indexed into Chroma DB upon startup.
